## Getting Started

Run this command first:

```bash
grepai init
```

It returns JSON telling you exactly what to do:

- `status: ready` → Use the `commands` provided
- `status: needs_setup` → Run the `next_step` command
- `status: needs_machine_setup` → Ask the user to configure
